2. 用例清单表

公共准备 PREP-RPT-r1（定义，尚未执行）

参数：用例 ID、发起身份（u1 或 u2）、任务前态（失败或 D-NF 中的具体非失败状态）。每例独立建立快照；不能使用其他用例运行后的 T1。

  1. 在获准的 CI／共享验收环境取得与 export-build-1 对应的构建、环境与入口记录。入口尚缺，待 GAP-01；本次不连接环境。
  2. 为本例分配独立可重建的数据域，绑定测试身份 u1 和 u2。二者是不同用户，不能把权限判断替换为固定允许或固定拒绝。
  3. 通过该构建获准的数据准备方式，建立一个属于 u1 的导出任务 T1，已有执行尝试集合恰为 {A1}，并将任务置于参数指定的前态。实际状态值和准备入口由交付方提供，不直接猜数据库或私有接口。
  4. 暂停或隔离本例以外会改变 T1 的处理者，在执行前记录权威快照 B：T1 的任务 ID、所属用户、任务状态及完整执行尝试集合 {A1}。观察渠道待 GAP-03 明确，不能仅凭按钮或 HTTP 状态码认定落库。
  5. 在本例指定身份下取得可提交对 T1 重试动作的正式入口。拒绝用例若页面不提供按钮，仍须使用已交付的正式操作契约验证服务端拒绝，不能以“看不到按钮”代替无副作用断言。

完成状态：身份绑定、前态和快照确定，数据域独立，正式入口与权威观察点可用。任一缺失则该例仍未验证，不擅自补造数据。

每例结束只清理本例数据域创建的 T1、尝试及临时认证绑定；保留脱敏证据与逻辑 ID 对应关系。清理入口未提供时先隔离数据并登记，不删除原有或他人资源。记录构建身份、环境、用例及数据行、发起身份、动作回执、操作前后权威快照、观察点和清理结果；执行报告另行追加，不修改本用例定义为“通过”。
